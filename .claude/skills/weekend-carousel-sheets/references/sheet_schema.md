# 構成シートの定義（Googleスプレッドシート）

ファイル名：`週末カルーセル_YYYY-MM-DD〜DD`（例：`週末カルーセル_2026-11-21〜23`）
1行目は見出し。見出し行を固定し、太字にする。

## タブ1「設定」（A列＝項目、B列＝値）

| 項目 | 例 | 説明 |
|---|---|---|
| 対象期間 | 11/21(土)〜23(月・祝) | 表紙と一覧に入る |
| 表紙の地域名 | 福山 | 表紙の大きい文字 |
| デザイン名 | 11月21−23日週末イベント情報 | Canvaのタイトル |
| 季節 | 秋 | SKILL.mdの月→季節の表で決める |
| 共通写真_モチーフ | 紅葉、稲穂 | |
| 共通写真_asset_id | MAHWHQuhllY | 表紙・一覧・CTAで共通 |
| 共通写真_説明 | 紅葉の中で笑顔の家族 | alt_textにも使う |
| 共通写真_出典 | AI生成 / ユーザー提供 | |
| 基準デザイン | DAHbFfdRAzI | |
| CanvaのURL | （作成後に記入） | |
| 作成日 | 2026-11-16 | |

## タブ2「ページ構成」（1行＝1ページ）

| 列 | 例 |
|---|---|
| 順 | 1 |
| 種別 | 表紙 / イベント / 一覧 / CTA |
| イベント番号 | ①（イベントの行だけ） |
| 見出し | 週末イベント情報 / イベント名 / 今週のイベント一覧 / お出かけの参考に！ |
| 写真 | 共通家族写真 / イベント写真 |
| 写真の出典 | AI生成 / チラシ / ユーザー提供 |
| メモ | |

並び：表紙 → イベント①〜N → 一覧 → CTA。表紙・一覧・CTAの「写真」は必ず「共通家族写真」にする。

## タブ3「イベント」（1行＝1イベント）

列名はCanvaのデータフィールド名と**完全に同じ**にする（`dataFieldLabel` と照合するため）。

| 列名 | 例 | ルール |
|---|---|---|
| ページ番号 | ① | 丸数字 |
| イベント名 | 誠之館マルシェvol.2 | 長い場合は2行 |
| サブタイトル | 同窓生のグルメ・雑貨・ステージが大集合 | 1行。イベント名が2行なら空にする |
| 開催地域名（福山・尾道など短く） | 福山 | 2〜3文字 |
| 参加者へ向けたひと言メッセージ（18文字以下） | 世代をこえて集おう | 18文字以下 |
| 開催場所（会場名） | iti SETOUCHI 1F | |
| 開催場所（住所） | 福山市西町1-1-1（福山駅から西へ徒歩7分） | |
| 開催日 | 11/21(土) | 曜日付き |
| 開催時間 | 11:00〜17:00 | |
| 入場料・チケット情報 | 入場無料（飲食などは有料） | 補足は（）で書く。2行目のグレー文字になる |
| Instagramアカウント（Mail・TEL） | @seishikandousoukai | |
| おすすめポイント（２点・各約30文字まとめ） | ・昨年約2,000人が…\n・同窓生はもちろん… | 「・」付きで2行。セル内で改行する |
| 写真キーワード | marche, outdoor, autumn | イベント写真をAIで作る場合に使う |
| 出典URL | https://… | |
| チェック | OK / 要確認：理由 | |
