# 週末イベントカルーセル（Googleスプレッドシート → Canva）

1回の実行で次の3つを順に行う。

1. **構成シート作成**：Googleスプレッドシートに、ページ構成とイベント情報をまとめる
2. **テンプレート挿し替え**：過去の投稿デザインを複製し、シートの内容をイベントごとに流し込む
3. **共通写真**：季節を感じる家族写真を1枚決め、表紙・一覧・CTAの3か所に同じ写真を使う

## 前提（変わったらここを更新）

| 項目 | 値 |
|---|---|
| 基準デザイン（過去の投稿） | `DAHbFfdRAzI`「11月21−23日週末イベント情報」 https://canva.link/egaofoierimwd5c |
| サイズ | 1080×1350（4:5）、全16ページ |
| 基準デザインのページ構成 | 1 表紙 ／ 2〜13 イベント①〜⑫ ／ 14〜16 CTA（同じページが3枚） |
| 色 | 紺 #2a3c6d（表紙）／ #003962（CTA）／オレンジ #d26102（イベントのタイトル） |
| Instagram | @info_fukuyama |

- 基準デザインは**絶対に編集しない**。必ず `copy-design` で複製してから作業する。
- 複製するとページIDと要素IDが変わる。要素は **ページの順番と `dataFieldLabel`** で特定する（下の表の要素IDは基準デザインのもので、参考用）。
- シートの列と各タブの定義は `references/sheet_schema.md` にある。

## ステップ1：構成シートを作る（Googleスプレッドシート）

1. イベント情報を集める。入力元の優先順は次のとおり。
   1. ユーザーが渡したもの（貼り付け・CSV・URL・チラシ）
   2. 前回のシートの「次回候補」タブ
   3. 上の2つがなければ、福山・備後・備中の週末イベントをWebで調べる（公式・主催者の情報を優先し、出典URLをシートに残す）
2. 新しいスプレッドシートを作る。名前は `週末カルーセル_YYYY-MM-DD〜DD`。
3. `references/sheet_schema.md` のとおり、「設定」「ページ構成」「イベント」の3タブを作って値を入れる。
   - 「設定」タブ：対象期間・表紙の地域名・季節・共通写真の情報
   - 「ページ構成」タブ：表紙 → イベント①〜N → 一覧 → CTA の順に1行1ページ
   - 「イベント」タブ：1行1イベント。列名はCanvaのデータフィールド名と完全に同じにする
4. 文字数をチェックする。超えていたらシート上で短くし、`チェック` 列に「要確認」と書く。
   - ひと言メッセージ：18文字以下
   - おすすめポイント：2点・各約30文字
   - イベント名：1行に収まらない場合は2行（サブタイトルは使わない）
5. **ここで一度止めて、シートのURLをユーザーに見せ、確認をもらう。** 定期実行のときは止めずに進め、判断した内容を最後の報告に書く。

## ステップ2：テンプレートを挿し替える（Canva）

### 2-1. 複製とページ数の調整
1. `copy-design` で `DAHbFfdRAzI` を複製し、タイトルを `M月D−D日週末イベント情報` にする。
2. ページ数をイベント数Nに合わせる。
   - N < 12：余ったイベントページ（後ろから）を削除する
   - N > 12：イベントページを `merge-designs` で複製して増やす
   - CTAページ3枚のうち1枚目を **一覧ページ** に作り替え（2-4）、2枚目は削除し、3枚目をCTAとして残す。
   - 最終的な並び：**表紙 → イベント①〜N → 一覧 → CTA**
3. `read-design`（`open_transaction: true`）で各ページの要素を読み、`dataFieldLabel` ごとの locator_id を控える。

### 2-2. 表紙（1ページ目）
| dataFieldLabel | 入れる値 | 基準の要素ID |
|---|---|---|
| 参加者へ向けたひと言メッセージ（18文字以下） | 地域名（例：福山）213pt | LB6S8mCxCM3dTn6r |
| 開催日 | 対象期間（例：11/21(土)〜23(月・祝)）62pt | LBcMx8NrL06P4QlV |
| イベント名 | 「週末イベント情報」74.7pt | LBJg3w9h7FvJrFyF |
| （画像）全面写真 | **共通家族写真**（ステップ3） | LBB6KhMpD1Fbd4CP |

文字は右上に載るので、写真の人物は下〜左寄りの構図にする。

### 2-3. イベントページ（①〜N）
「イベント」タブの1行を1ページに流し込む。列名＝`dataFieldLabel`。

| dataFieldLabel | 内容 |
|---|---|
| ページ番号 | ①②…（丸数字） |
| イベント名 | タイトル（オレンジ） |
| サブタイトル | タイトル下の1行 |
| 開催地域名（福山・尾道など短く） | 左上の地域ラベル |
| 参加者へ向けたひと言メッセージ（18文字以下） | 吹き出し |
| 開催場所（会場名） | 📍 会場名 |
| 開催場所（住所） | 住所（小さい文字） |
| 開催日 | 📅 |
| 開催時間 | ⏰ |
| 入場料・チケット情報 | 💰（補足は2行目にグレーで） |
| Instagramアカウント（Mail・TEL） | 左下の連絡先 |
| おすすめポイント（２点・各約30文字まとめ） | 下のオレンジ枠。「・」付きで2行 |

レイアウトのルール：
- テキストは `replace_text` で置き換える（`find_and_replace_text` は反映されないことがある）。書式が崩れたら `format_text` で直す。`add_text` は書式が合わないので使わない。
- タイトルが1行に収まらない場合は2行にし、サブタイトルを削除してタイトルを帯の上下中央に置く。それでも収まらなければ最小50ptまで縮小する。
- 地域ラベルは2文字なら既定サイズ、3文字以上なら20ptにする。
- 右側の情報欄は下端がtop 1078を超えないようにする。2行になる項目は27〜31ptに下げる。
- **イベントの写真**（上部の見出し写真・左下のチラシ枠）はイベントごとに変える。共通家族写真は使わない。探す順番：ユーザーが用意した写真 → チラシ画像 → `generate-image`（LANDSCAPE_3_2、写実的に、`写真キーワード` 列を使う）。

### 2-4. 一覧ページ（CTAページを作り替えたもの）
CTAページの構造（背景写真＋黒30%の重ね＋白い半透明の枠＋紺の帯）をそのまま使い、文字だけ差し替える。

| 要素（基準のID） | 変更内容 |
|---|---|
| 見出し LBgspvpsHsR6tS9F「お出かけの参考に！」 | 「今週のイベント一覧」 |
| 本文 LBrRXX3mqK9Lrw04 | 1行1イベント：`① 11/21(土) 誠之館マルシェ［福山］`。N行入るように文字サイズを下げる（目安：12件で26pt、行間1.5）。白枠の中に収まるよう、本文の幅と位置・枠の高さを調整する |
| アカウントアイコン LBfckfYjzZvt9GZD・@info_fukuyama LBfrqhlDcnJW364j | 削除する（一覧が入るスペースを空ける） |
| 下の帯 LBrZ9CcLWz0fw13V | 「保存して週末の予定に！」 |
| 背景 | **共通家族写真**（ステップ3） |

会期が長いイベントには「※M/Dまで」を添える。

### 2-5. CTA（最終ページ）
文字はそのまま使う。背景だけ **共通家族写真** に替える。黒30%の重ね（LBbWzFMpvjxg236c）は文字を読みやすくするために残す。

## ステップ3：季節の家族写真を共通で入れる

1. 「設定」タブの `季節` を、対象期間の月から決める。

   | 月 | 季節 | 写真のモチーフ例 |
   |---|---|---|
   | 3〜4月 | 春 | 桜並木、菜の花 |
   | 5〜6月 | 初夏 | ばら（福山ばら祭）、新緑 |
   | 7〜8月 | 夏 | 海辺、ひまわり、浴衣・花火 |
   | 9〜11月 | 秋 | 紅葉、稲穂、コスモス |
   | 12月 | 冬（クリスマス） | イルミネーション、ニット |
   | 1〜2月 | 冬 | 冬の晴れ空、初詣、梅 |

2. 写真を1枚決める。探す順番：
   1. 「設定」タブの `共通写真_asset_id` に、同じ季節の写真がすでに登録されていればそれを使う
   2. ユーザーがCanvaにアップロードした家族写真
   3. `generate-image`（PORTRAIT_4_5、写実的な写真）。プロンプト例：「{季節モチーフ}の中で笑顔の日本人の家族（両親と子ども）、自然光、写真の上半分は空や背景で余白が多い、人物は画面の下半分に配置」
3. 決めた写真の asset_id と説明を「設定」タブに書く。
4. **同じ asset_id を3か所に入れる**：
   - 表紙：画像要素（基準 LBB6KhMpD1Fbd4CP）に `update_fill`
   - 一覧・CTA：背景はページの背景画像なので、まずページの locator_id に `update_fill` を試す。だめなら `insert_fill`（top 0 / left 0 / 1080×1350）で入れ、`layer_element` で一番後ろに回し、元の背景は残っていてもよい
   - 位置合わせは `crop_media` で行う。表紙は人物の顔に文字が重ならないように、一覧とCTAは人物が白枠の外（下の方）に見えるようにする
5. alt_text は3か所とも同じ内容にする（例：「紅葉の中で笑顔の家族」）。

---

## ステップ4：確認・保存・報告

1. 全ページのサムネイルを見て、次の点を確認する。
   - 文字のはみ出し・重なり・誤字（例：「鞆」が別の字に化けていないか。U+9786）
   - 表紙・一覧・CTAの写真が同じものになっているか
   - ページの並びが 表紙 → ①〜N → 一覧 → CTA になっているか
2. ユーザーにプレビューを見せ、承認をもらってから `edit-design` で `commit` する（定期実行のときは保存してから報告する）。
3. 「設定」タブに CanvaのURL と作成日を書く。
4. 報告は短く次の内容にする：シートのURL、CanvaのURL、AI生成の写真を使ったページ、「要確認」にした項目、直せなかったこと。

## 注意
- AI生成の写真は架空の人物・風景なので、報告で必ず伝える。実在のイベント会場の写真のように見せない。
- 主催者の情報と食い違いがあれば、シートの `チェック` 列に書いて、勝手に補わない。
- PCの写真をCanvaへ直接アップロードできない場合は、AI生成で代わりに用意したことを報告に書く。
